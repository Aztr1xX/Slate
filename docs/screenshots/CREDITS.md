# Screenshot credits

The README screenshots use real, openly licensed footage and music, so they show Slate the way it's meant to be
used: reviewing takes before an edit.

- **Footage:** *Tears of Steel* (2012), © Blender Foundation, [mango.blender.org](https://mango.blender.org),
  licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The clips in the screenshots
  ("Bridge, take 1" and so on) are short excerpts of the finished film, cropped to remove burned-in subtitles.
  The transcript text is the film's own dialogue.
- **Music:** "Choice" (drum and bass) by Admiral Bob (admiralbob77), licensed under
  [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), from the librosa example audio collection.

Markers, notes, ratings and selects in the screenshots were added for the demo. To make new screenshots, run
`slate --tour <folder> "<clip>"` with `SLATE_TOUR_AUDIO` pointing at a music file (see `src/main.cpp`).
